# Setup: turning this folder into your GitHub project

This folder contains the source (`src/`, `index.html`, `public/`, docs). `package.json` and the
lockfile are generated by npm on your machine so the versions are real and current.

1. Scaffold a Vite React project (name it after your roll number):
   ```
   npm create vite@latest 24I1234-meal-box -- --template react
   cd 24I1234-meal-box
   npm install
   npm install react-router-dom
   ```
2. Delete the template's `src/` folder and `index.html`, then copy these from this folder into the project:
   `src/`, `index.html`, `public/_redirects`, `vercel.json`, `.gitignore`, `README.md`, `DECISIONS.md`.
3. In `package.json` add under `"scripts"`:  `"test": "node --test"`
   Make sure `"type": "module"` is present (the Vite template already has it).
4. Check it runs: `npm run dev`, open the printed address, open DevTools and confirm there are no errors or warnings.
5. Run the tests: `npm test` (expect 6 passing).
6. `git init`, make your **first commit now**, create a public GitHub repo, push, and keep committing
   as you edit (see the five milestones in the assignment brief). Do not upload it all at the end.
7. Deploy:
   - **Netlify:** import the GitHub repo, build command `npm run build`, publish directory `dist`. The `_redirects` file makes refreshes on `/items/...` work.
   - **Vercel:** import the repo (Vite preset). `vercel.json` handles the refresh rewrite.
   - Afterwards open `/items/chicken-biryani-box` directly and refresh to verify FR19.
8. Fill every `ADD` / `YOUR` placeholder in `README.md` and `DECISIONS.md`.
